# Python Spiral Art

A colorful spiral drawing made with Python's turtle module.

## How to run

1. Install Python 3
2. Download `spirale.py`
3. Run in a terminal:

   python spirale.py

## How it works

- Draws a spiral with lines that get longer each step
- Cycles through a list of colors
- Uses a `for` loop to repeat the drawing 120 times

## What I learned

- Using the `turtle` module to draw
- Using `for` loops and `range()`
- Using lists and the `%` operator to cycle colors
